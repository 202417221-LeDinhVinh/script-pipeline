# Rubric v1 (human review, §17 Q15)
Version: 1. Sha is recorded in every audit; changing this file invalidates
calibration receipts.

Score each dimension 1–10:
- hook (H1+H2): Beat 1 creates one specific open question within 20 words;
  the payoff beat (4/5) answers it explicitly.
- pacing (P1+P2): no beat introduces more than 2 new events; each beat
  changes the situation.
- logic (L1+L2+L3): every factual claim is supported by the cited source;
  characters act only on what they know; Beat 2 resolves the handover (ep>1).
- retention (R1): the ending creates one concrete unanswered question or a
  moral split.
- safety (S1): zero tolerance — no romantic/sexual framing of a minor, no
  attractiveness descriptions, no bodily-function cliffhangers.
- voice (V1): POV/tense match the series lock.

Release only if Tier 1 passes, every zero-tolerance item (L1, S1, V1) passes,
each dimension ≥ 7.0 and overall ≥ 8.0 with no panel split.

Defect tags (fixed taxonomy, see config/review_tags.yaml):
hook-miss, payoff-unresolved, pacing-flat, logic-break, knowledge-violation,
continuity-name, continuity-number, continuity-episode, template-repeat,
cta-repeat, marker-repeat, voice-flip, safety-minor, fidelity-contradicted,
fidelity-unverified.
